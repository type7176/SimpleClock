# SimpleClock

Часы на ESP32 с синхронизацией времени через NTP и управлением через MQTT.

## Особенности
- Точное время с любого NTP-сервера (по умолчанию - pool.ntp.org)
- Крупный кастомный шрифт на I2C-дисплее 1602
- Управление дисплеем через MQTT
- Автоматическая синхронизация времени (раз в час)

## Компоненты
- ESP32 (любая версия)
- LCD 1602 с I2C модулем (адрес 0x27)

## Подключение
| LCD | ESP32 |
|-----|-------|
| VCC | 3.3V/5V |
| GND | GND |
| SDA | GPIO21 |
| SCL | GPIO22 |

## Управление через MQTT
- Брокер: укажите параметры в коде
- Топик для управления: clock/display
 1 - включить дисплей
 0 - выключить дисплей

## Быстрый старт
1. Установите библиотеки из файла libs.txt
2. Настройте Wi-Fi и MQTT в коде
3. Загрузите скетч в ESP32
